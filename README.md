# UniFind – Smart Lost & Found System

UniFind is a Flutter-based mobile application designed to provide a simple and organized solution for managing lost and found items within a university campus.

The application allows users to report lost or found items, provide item details, upload images, and browse reported items to make the process of finding and recovering belongings easier.

## 🎯 Project Objective

The main objective of UniFind is to create a centralized platform where university students can easily report lost or found belongings and find relevant information about items reported on campus.

## ✨ Features

- Report Lost Items
- Report Found Items
- Upload Item Images
- Add Item Name and Description
- Select Item Category
- Add Location Details
- Browse Reported Items
- Search and Filter Items
- View Item Details
- Firebase Integration for Data Storage
- Firebase Storage for Image Uploads

## 🛠️ Technologies Used

- **Flutter**
- **Dart**
- **Firebase Authentication**
- **Cloud Firestore**
- **Firebase Storage**
- **Image Picker**

## 🔄 How It Works

1. The user opens the UniFind application.
2. The user can report a lost or found item.
3. Item details such as name, description, category, and location can be added.
4. An image can be selected and uploaded with the item report.
5. Item information is stored using Firebase.
6. Reported items can be viewed from the application dashboard.
7. Users can search for and view details of reported items.

## 🔥 Firebase Integration

UniFind uses Firebase for backend services:

- **Firebase Authentication** – User authentication.
- **Cloud Firestore** – Stores information about lost and found items.
- **Firebase Storage** – Stores uploaded item images.
